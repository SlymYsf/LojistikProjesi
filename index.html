Lojistik Otomasyonu Veritabanı Projesi

TBL331 Veritabanı Yönetim Sistemleri - 2025-2026 Bahar Dönem Projesi

Proje Özeti

Bu proje, bir lojistik firmasının kargo kabul, araç atama ve sefer takip süreçlerini uçtan uca yönetmek amacıyla geliştirilmiş kapsamlı bir veritabanı otomasyonudur.

Teknik Altyapı

  • Veritabanı: MS SQL Server (View, Stored Procedure, Trigger, Index ve 5N normalizasyon kuralları)
  • Arka Uç (Back-end): Node.js REST API
  • Ön Uç (Front-end): HTML5, CSS3, JavaScript (Fetch API)
